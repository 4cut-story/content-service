= content-service API
:doctype: book
:icons: font
:toc: left
:toclevels: 2

만화함, 올리기, 피드, 좋아요·댓글, 팔로우. 이 문서는 테스트(Spring REST Docs)가 만든 실제 요청·응답으로 만든다.

* 외부 경로는 web → api-gateway를 거친다. 게이트웨이가 JWT를 검증해 `X-User-Id`를 붙인다. 이 헤더가 없으면 401.
* 볼 수 없는 게시물·남의 만화는 없는 것(404)으로 본다.
* 목록은 커서 페이지 `{items, nextCursor}`다. `nextCursor`가 null이면 마지막 페이지다. `size`는 기본 20, 최대 50.
* 오류는 모두 `{error: {code, message, traceId}}` 형식이다 (docs `api-conventions.md`).
